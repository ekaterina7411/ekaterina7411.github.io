Проект

HR Automation

Интеграция HH.ru с Битрикс24

Автоматизация обработки откликов на вакансии. Скрипт забирает данные с HH.ru, проверяет контакты на дубли с помощью MD5-хэширования и автоматически создаёт лиды в CRM.

🐍 Python 🔗 REST API 🔒 MD5 Хэширование 📊 Битрикс24

🎯 Задача и решение

Ручной перенос откликов из HH.ru в CRM отнимает время и приводит к человеческим ошибкам и дублям контактов. Этот проект решает проблему полностью автоматически.

Алгоритм работы: 1. Скрипт по расписанию опрашивает API HH.ru на наличие новых откликов.
2. Данные нормализуются, а контактные данные (телефон/email) хэшируются через MD5.
3. Происходит проверка: если хэш уже есть в базе, отклик помечается как дубликат и пропускается.
4. Если контакт новый, в Битрикс24 через REST API автоматически создаётся новый лид со всеми данными кандидата.

🚀 Дашборд мониторинга

Для контроля работы интеграции создан веб-дашборд. Он показывает статистику в реальном времени: количество обработанных откликов, созданных лидов, найденных дубликатов и ошибок, а также подробные логи каждого шага.

💡 Технические детали

Проект написан на Python. Для взаимодействия с внешними системами используются официальные REST API (HH.ru и Битрикс24). Хэширование через MD5 гарантирует, что даже при разных форматах записи номера телефона (например, +7 и 8) дубликаты будут корректно выявлены. Все ошибки логируются для быстрого анализа и отладки.
